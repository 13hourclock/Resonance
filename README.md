# Resonance v1 (first game)

Wilbow Shmesh's first game: an Android, gesture-only musical life sim where gene-built creatures ("ohms") are instruments with their own musical minds. Built with Capacitor and plain JavaScript (Web Audio). It's now retired and kept as a concept reference for its successor, **The Journey Ohm (Resonance 2.0)**.

**Start with [HANDOFF_FOR_AI.md](HANDOFF_FOR_AI.md)**: status, reading order, how to run it and test it, and what was excluded for security. Release history is in [CHANGELOG.md](CHANGELOG.md).

- Code snapshot: `4faca7f` (Oct 25 2026). The game code is identical to the last shipped APK, v0.8b10 (vc35, tag `508432e`).
- Release signing: bring your own keystore. No keys or passwords are in this repo; never commit them.
